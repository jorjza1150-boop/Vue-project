# Chokanan Noikoon — Home

เว็บเบื้องต้นด้วย Vue.js 3, Bootstrap 5 และ Vite

ผู้จัดทำ: **Chatree Puangpachung**  
รหัสนักศึกษา: **69702075**

## เริ่มใช้งาน

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน terminal

## สร้างไฟล์สำหรับเผยแพร่

```sh
npm run build
npm run preview
```

ไฟล์ที่ build แล้วอยู่ใน `dist/` หน้า Home มีเมนูเลื่อนไปยังข้อมูลผู้จัดทำและข้อมูลโปรเจกต์ พร้อมเมนูมือถือ ใช้ Bootstrap Grid และปรับแต่งรูปแบบด้วย CSS ใน `src/style.css`

ฟอนต์โหลดจาก Google Fonts หากไม่ได้เชื่อมต่ออินเทอร์เน็ตจะใช้ฟอนต์สำรองของเครื่อง
